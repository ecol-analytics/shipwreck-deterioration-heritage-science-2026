# Data provenance and reuse

This repository contains derived environmental data and an anonymised
archaeological calibration dataset in addition to original software
code. The MIT licence in `LICENSE` applies to the original software code
and does not relicense these data.

## Derived environmental model inputs

`data/model_inputs/publication_model_inputs.nc` is a frozen, derived
dataset prepared for reproduction of the analyses reported in:

*Environmental forcing and deterioration trajectories in submerged
shipwreck heritage*.

The environmental fields were derived from the following source
products:

### Copernicus Marine

-   `cmems_mod_glo_phy_my_0.083deg_P1M-m` --- physical ocean variables
-   `cmems_mod_glo_phy_my_0.083deg_static` --- static physical variables
-   `cmems_mod_glo_bgc_my_0.25deg_P1M-m` --- biogeochemical variables
-   `cmems_mod_glo_wav_my_0.2deg_PT3H-i` --- wave variables

These derived fields remain subject to the applicable Copernicus Marine
terms and acknowledgement requirements. Users wishing to reuse or
redistribute the source-derived environmental data should consult the
current Copernicus Marine licence and citation requirements for the
relevant products.

Copernicus Marine Service: https://marine.copernicus.eu/

### EMODnet Geology

Seabed substrate information was derived from the EMODnet Geology
**Seabed Substrate -- Multiscale -- Folk 7** product.

The EMODnet source product is made available under its applicable source
licence (CC BY 4.0 for the Folk 7 seabed-substrate product). Reuse
should retain the required source attribution and comply with the
current terms associated with the source dataset.

EMODnet Geology: https://emodnet.ec.europa.eu/en/geology

## Archaeological calibration data

`data/calibration/wreck_calibration.csv` is an anonymised and reduced
calibration dataset derived from archaeological wreck-condition and age
records supplied by David Gregory (National Museum of Denmark).

The public calibration file contains only the variables required to
reproduce the fitted calibration model. Wreck names, site identifiers
and geographic coordinates have been removed because the underlying
records include restricted heritage information.

Inclusion of this reduced dataset in the repository is for
reproducibility of the reported analysis. It does not relicense,
transfer ownership of, or grant broader reuse rights to the underlying
archaeological records.

## Repository-generated derived products

`data/gam_age_curve.csv` and files under `outputs/` are generated by the
analysis workflow from the inputs described above. Their interpretation
and reuse should retain appropriate attribution to the associated
manuscript and to relevant upstream data sources where applicable.
